# Data

| path | what it is |
|---|---|
| `sklearn/` | **The default knowledge base:** the full [scikit-learn user guide](https://scikit-learn.org/stable/user_guide.html) (44 pages, ~140k words), release 1.9.1, converted to Markdown |
| `sklearn_eval.jsonl` | labeled questions for `python -m docqa.evaluate`: each names the page and section that answers it |
| `ml_notes/` | four short notes on ML topics; a small corpus the fast tests use |
| `index.joblib` | the built retrieval index (git-ignored; rebuild with `python -m docqa.ingest`) |

## The scikit-learn corpus

`sklearn/` is generated by [`scripts/fetch_sklearn_docs.py`](../scripts/fetch_sklearn_docs.py),
which downloads the user guide's reStructuredText at a pinned release tag and
converts it to Markdown. It keeps headings, prose, math and code, and drops
Sphinx plumbing such as labels and image options. Each file begins with a comment
linking its source.

The scikit-learn documentation is © the scikit-learn developers, BSD-3-Clause;
the license is in [`sklearn/LICENSE`](sklearn/LICENSE).

## Use your own documents

Point `RAG_DOCS_DIR` (or `--docs`) at a folder of `.md`, `.txt` or `.pdf`
files and rebuild the index (or upload files in the web UI):

```bash
python -m docqa.ingest --docs path/to/your/docs
```
